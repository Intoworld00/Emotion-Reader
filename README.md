# 🧠 Emotion Reader

**Emotion Reader** is a small C-based interactive program that attempts to identify your current emotional state through a series of questions.

By answering a short questionnaire, the program selects an emotion and displays a corresponding message.

> Discover what your answers might say about your current mood!

---

## ✨ Features

- 📝 **Username identification** — Enter a username before starting.
- 🌍 **Country input** — Provide your country as optional information.
- 💭 **Mood questionnaire** — Answer questions about your day and experiences.
- 🎵 **Music preferences** — Your music taste helps determine the result.
- ❤️ **Relationship questions** — Explore the romantic emotion category.
- 😂 **Happiness detection** — Identify positive experiences.
- 🌿 **Calmness detection** — Identify relaxing situations.

## 🎭 Available Emotions

| Emotion | Description |
|:---|:---|
| 😢 Sad | Associated with having a difficult or sad moment. |
| 😊 Happy | Associated with funny or enjoyable experiences. |
| 🌿 Calm | Associated with peaceful and relaxing situations. |
| ⚡ Energetic | Associated with listening to rock music. |
| ❤️ Romantic | Associated with relationship-related experiences. |

## ⚙️ Requirements

- A C compiler (GCC recommended).
- Windows operating system (the current version uses Windows commands).
- The project repository files:
  - `repositories/mind_musics.h`
  - `repositories/mind_abreg.h`

## 🚀 Installation & Execution

**1. Clone the repository**

```bash
git clone https://github.com/Intoworld00/Emotion-Reader/
```

**2. Enter the project directory**

```bash
cd Emotion-Reader
```


**3. Run Emotion Reader**

```bash
./Mind.exe
```

## ⚠️ Disclaimer

Emotion Reader is an experimental entertainment project.

It does **not** scientifically detect, diagnose, or accurately measure human emotions. Its results are based entirely on the answers provided by the user.
